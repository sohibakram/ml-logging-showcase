
# Student Performance Prediction - ML Logging Showcase

## Project Overview

This project is an end-to-end Machine Learning pipeline built to demonstrate:

- Professional logging in ML projects
- Exception handling
- Modular project structure
- Data ingestion
- Data transformation
- Model training
- GitHub project organization

The project predicts student math scores using machine learning.

---

# Features

- Structured ML pipeline
- Logging at every major stage
- Custom exception handling
- Train-test split
- Model evaluation using R2 Score
- Clean modular coding structure
- GitHub-ready project
